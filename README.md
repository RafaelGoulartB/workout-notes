# Life Notes 📝

A beautiful, minimal journal app built with Flutter. Capture your thoughts, memories, and everyday moments.

## Features

- ✍️ **Write notes** — Capture your thoughts anytime
- 📖 **Browse entries** — Scroll through your notes in a clean list
- ✏️ **Edit & update** — Revisit and refine your entries
- 🗑️ **Delete** — Remove notes you no longer need
- 🌙 **Dark mode** — Automatically adapts to your system theme
- 💾 **Persistent storage** — Notes are saved locally on your device

## Getting Started

### Prerequisites

- Flutter SDK 3.44+
- Dart 3.12+

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/life_notes.git

# Navigate to the project
cd life_notes

# Get dependencies
flutter pub get

# Run the app
flutter run
```

### Building for release

```bash
# Android
flutter build apk --release

# iOS
flutter build ios --release
```

## Tech Stack

- **Flutter** — Cross-platform UI framework
- **Shared Preferences** — Lightweight local key-value storage
- **UUID** — Unique identifier generation
- **Intl** — Date formatting
